Aeon

Productividad local, con tu calendario a mano

Aeon es una aplicación de escritorio local-first para organizar hábitos, objetivos, tareas y actividades. La integración con Google Calendar es opcional y se activa únicamente cuando el usuario autoriza la conexión.

Integración con Google Calendar

Cuando la conexión está habilitada, Aeon puede leer tus calendarios y eventos, y crear, editar o eliminar eventos que solicites desde la aplicación. La conexión se realiza mediante OAuth y PKCE; Aeon no requiere un client secret en tu computadora.

Descarga y código fuente

El código fuente y las versiones disponibles de Aeon se publican en el repositorio de GitHub del proyecto.
