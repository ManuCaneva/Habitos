Política de privacidad de Aeon

Última actualización: 3 de septiembre de 2026

Qué es Aeon

Aeon es una aplicación de escritorio local-first para organizar hábitos, objetivos, tareas y actividades. La aplicación guarda sus datos de productividad localmente en la computadora del usuario.

Datos de Google Calendar

Si el usuario decide conectar Google Calendar, Aeon solicita permiso para acceder a sus calendarios y eventos. Ese acceso permite:

  • Leer calendarios y eventos para mostrarlos en Aeon.
  • Crear eventos que el usuario solicite desde Aeon.
  • Editar eventos que el usuario solicite modificar desde Aeon.
  • Eliminar eventos que el usuario solicite borrar desde Aeon.

Almacenamiento y uso

Los tokens de autenticación de Google se almacenan localmente en la computadora del usuario para mantener la sesión y renovar el acceso cuando sea necesario. Aeon no envía esos tokens a un servidor propio, no vende datos personales y no comparte los datos de Google Calendar con terceros.

Aeon usa los datos de Google Calendar únicamente para proporcionar las funciones de sincronización solicitadas por el usuario. No usa esos datos para publicidad ni para crear perfiles de usuarios.

Desconectar y revocar el acceso

El usuario puede desconectar Google Calendar desde Settings dentro de Aeon. Al desconectar, la aplicación elimina los tokens y los eventos sincronizados localmente, y solicita la revocación del acceso ante Google cuando es posible. El usuario también puede revocar el acceso desde la configuración de seguridad de su cuenta de Google.

Cambios en esta política

Podemos actualizar esta política cuando cambien Aeon o sus integraciones. La fecha de última actualización se indica al comienzo de esta página.

Contacto

Para consultas sobre privacidad o sobre el uso de Google Calendar en Aeon, contactá al responsable del proyecto mediante el email publicado en el repositorio de GitHub.
