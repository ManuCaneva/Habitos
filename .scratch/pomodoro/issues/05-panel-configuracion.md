# 05: Panel de configuración

**What to build:** el panel dentro de la Vista Pomodoro que permite editar la configuración: duración de enfoque, descanso corto y descanso largo, intervalo del descanso largo, los dos toggles de auto-start, y el control de volumen con mute. Los cambios se aplican y persisten de inmediato.

**Blocked by:** 04 (Vista Pomodoro y navegación)

**Status:** done

- [x] Se puede editar la duración de enfoque, de descanso corto y de descanso largo.
- [x] Se puede editar el intervalo del descanso largo (cada cuántas sesiones).
- [x] Se pueden alternar los toggles de auto-start de descanso y de enfoque.
- [x] Se puede ajustar el volumen y activar mute.
- [x] Los cambios persisten y se reflejan en el store.
- [x] Tests del panel cubren la edición de cada campo y la emisión de los cambios esperados.
